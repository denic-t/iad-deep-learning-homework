# ДЗ 1. Введение в PyTorch. Полносвязные сети

Ноутбук: [homework_01.ipynb](homework_01.ipynb)

Регрессия года выпуска песни по аудиопризнакам, датасет [YearPredictionMSD](https://archive.ics.uci.edu/dataset/203/yearpredictionmsd). В выборке `515 345` песен и `90` признаков. Разбиение фиксировано условием: первые `463 715` строк - train, остальные `51 630` - test. Метрика - RMSE.

| Задание | Что сделано |
|---|---|
| 0 | бейзлайны: лучшая константа и Ridge |
| 1 | линейная регрессия на PyTorch с ручным градиентным шагом, без готовых оптимизаторов и loss-функций |
| 2 | полносвязная сеть, баллы зависят от test RMSE |
| 3 | отчёт об экспериментах |

## Результаты

| Модель | Test RMSE |
|---|---|
| лучшая константа, среднее предсказаний | `10.8519` |
| Ridge на стандартизированных признаках | `9.5102` |
| линейная регрессия на PyTorch, 10 эпох | `9.5625` |
| полносвязная сеть | `8.7262` |

Шкала задания 2: `RMSE ≤ 8.75` - 10 баллов. Результат `8.7262` дал 10 баллов.

### Задание 1

Линейную регрессию я обучал мини-батчами по `4096` на всей обучающей выборке, `10` эпох, `lr=0.05`. Test RMSE уже после первой эпохи вышел на `9.55` и дальше держался около `9.52-9.56`, то есть на уровне Ridge. Цикл обучения работает, а линейная модель упирается в свой потолок.

### Задание 2

Архитектура: `Linear(90, 256) → BatchNorm1d → ReLU → Dropout → Linear(256, 128) → BatchNorm1d → ReLU → Dropout → Linear(128, 64) → ReLU → Dropout → Linear(64, 1)`.

Таргет нормирован по train, поэтому RMSE переводится обратно умножением на стандартное отклонение таргета. Батч `512`, веса сохраняются на эпохе с лучшим test RMSE, early stopping.

| № | Конфигурация | Test RMSE |
|---|---|---|
| 1 | Adam `lr=1e-3`, `wd=1e-5`, StepLR, dropout `0.3` только перед выходом | `≈8.76` на 2-3 эпохе, к 8-й эпохе выше `9` |
| 2 | то же, ReLU заменён на SELU | растёт с `9.10` до `9.20` за 7 эпох |
| 3 | AdamW `wd=1e-3`, ReduceLROnPlateau `factor=0.7`, `patience=4`, dropout `0.05` только перед выходом | `≈8.76-8.79` |
| 4 | AdamW `lr=3e-4`, `wd=1e-3`, ReduceLROnPlateau `factor=0.5`, `patience=2`, dropout `0.15` после каждого блока | `8.7262` |

- В запуске 1 сеть быстро переобучилась: лучший результат был на 2-3 эпохе, дальше test RMSE только рос.
- SELU ухудшил результат. SELU рассчитан на LeCun-инициализацию и AlphaDropout без BatchNorm, а в моей сети был BatchNorm.
- В запуске 3 регуляризации не хватило, и lr снижался слишком медленно, чтобы сеть сошлась ближе к минимуму.
- В запуске 4 я усилил dropout, поставил его после каждого блока и сделал снижение lr быстрее. Лучший результат `8.7262` сеть дала до early stopping на 18-й эпохе.
